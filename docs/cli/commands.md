# `praxis` commands

Generated by `docs/cli/generate.py` from the release build: each command's `--help` and a real
`--json` result (trimmed: arrays show 2 items, long strings are cut, paths shortened). Field by
field contract: [../contracts/cli.md](../contracts/cli.md). Overview, errors and environment:
[README.md](README.md).

```text
Praxis Sound: score-driven music and sound design

Usage: praxis [OPTIONS] <COMMAND>

Commands:
  render          Render a score (or project) file to audio, with measurements
  validate        Validate a score file and report issues
  schema          Print or write the published JSON Schemas (score, patch, and the ScorePlan as `plan`)
  generate        Plan a Score from a brief (or compose an agent-written ScorePlan) into a project
  edit            Apply a scoped edit to a project (FR-7): an instruction, or an EditPlan you wrote
  variations      Make N alternates of a selection (FR-8), each rendered to variations/<i>.wav and checked. Nothing is committed (keep one of a sound's with `keep-variation`)
  ask             Make a take in a sound folder: a brief for a new sound, else a scoped edit of the current take. Renders takes/<n>/mix.wav, checks it and records it in takes.json
  takes           List a sound's takes, the current take and the live score
  restore         Go back to take N (an undoable patch); it becomes the current take
  keep-variation  Commit a variation made with `variations --sound` as a new take
  open-view       Ask the app to show a panel view of a sound (overview, rhythm, notes, mix, export)
  check           Measure a render against its Score. Exits 1 if any check fails
  analyze         Measure an audio or video clip: its complete Sound Profile
  library         The reference library: saved, tagged Sound Profiles (never audio)
  match           Make something like a reference clip: a new project with its character, refined by rendering and measuring until the similarity stops improving (FR-14 to FR-18)
  export-midi     Export a score (or project) as a Standard MIDI File
  packs           List or install instrument packs from packs/index.json
  presets         The planner's presets and whether each can render here
  bench           Time a render on this machine: a 2-minute, 8-layer piece (or a score you give) against the 20x real-time target. Writes nothing
  key             Store or clear the Anthropic API key in the OS keychain (read from stdin)
  help            Print this message or the help of the given subcommand(s)

Options:
      --json     Print one JSON object on stdout instead of human-readable text
  -h, --help     Print help
  -V, --version  Print version
```

## `render`

Renders a score or project to WAV or FLAC and checks the result against the score (`check` in the payload). `--stems DIR` writes one file per layer.

```text
Render a score (or project) file to audio, with measurements

Usage: praxis render [OPTIONS] --out <OUT> <INPUT>

Arguments:
  <INPUT>  Score JSON (.score.json) or project (.praxis)

Options:
      --json                       Print one JSON object on stdout instead of human-readable text
  -o, --out <OUT>                  Output audio path
      --seed <SEED>                Override the score seed
      --format <FORMAT>            16, 24 or 32f (WAV), or flac / flac24 / flac16 [default: 24]
      --sample-rate <SAMPLE_RATE>  [default: 48000]
      --stems <STEMS>              Directory for per-layer stems (same format as the master)
      --skip-missing               Render only layers whose instrument is available here; list the rest in skipped_layers
  -h, --help                       Print help
```

```bash
praxis --json render fixtures/acceptance1.score.json -o a1.wav
```

## `edit`

A scoped edit of a project, from words or an EditPlan; only the bars and layers it names change. The project keeps an undo history.

```text

  <PROJECT>  The project (.praxis); written back when the edit changes anything

Options:
      --json                       Print one JSON object on stdout instead of human-readable text
      --prompt <PROMPT>            The instruction, e.g. "change the last four bars to add a subtle melody"
      --plan <PLAN>                An EditPlan JSON file (`-` reads stdin). No provider or key needed
      --provider <PROVIDER>        offline or claude. Default: claude when a key is available, else offline
      --model <MODEL>              
      --seed <SEED>                [default: 1]
      --render <RENDER_OUT>        Also render the edited score to this file and check it
      --format <FORMAT>            16, 24 or 32f (WAV), or flac / flac24 / flac16 [default: 24]
      --sample-rate <SAMPLE_RATE>  [default: 48000]
      --stems <STEMS>              Directory for per-layer stems (same format as the master)
      --skip-missing               Render only layers whose instrument is available here; list the rest in skipped_layers
```

## `ask`

Makes a take in a sound folder: the first request is the brief, later ones are scoped edits of the current take (`--bars` with `--layer`), a hand edit (`--patch`), or a request about a reference clip (`--reference`). With an API key the sound assistant carries it out.

```text
Make a take in a sound folder: a brief for a new sound, else a scoped edit of the current take. Renders takes/<n>/mix.wav, checks it and records it in takes.json

Usage: praxis ask [OPTIONS] <SOUND> <TEXT>

Arguments:
  <SOUND>  The sound folder, or a bare name under PRAXIS_HOME/sounds
  <TEXT>   The request in words

Options:
      --json
          Print one JSON object on stdout instead of human-readable text
      --who <WHO>
          "You" (default) or an agent's name
      --bars <BARS>
          Hold the edit to these bars of --layer, e.g. 13-16
      --layer <LAYER>
          The layer the scope is on (with --bars)
      --patch <PATCH>
          A hand edit: commit this ScorePatch JSON file (`-` reads stdin) instead of planning
      --title <TITLE>
          
      --provider <PROVIDER>
          `claude` (the sound assistant; the default when an API key is available) or `offline` (the rule planner)
      --model <MODEL>
          The assistant's model (default claude-opus-5-5)
      --effort <EFFORT>
          The assistant's effort: low, medium (default), high, xhigh or max
      --max-steps <MAX_STEPS>
          Tool calls the assistant may make for this request (default 16)
      --seed <SEED>
          Default: the new take's number
      --skip-missing
          
      --include-score
          Include the take's full score in the output
      --reference <REFERENCE>
          A reference clip the request is about; "make something like this" runs the match loop
      --reference-library <REFERENCE_LIBRARY>
          A reference-library entry id instead of a clip
  -h, --help
          Print help
```

Example (exit 0):

```bash
praxis --json ask calm a calm felt piano loop in A minor, 16 bars at 128 BPM, with a soft kick from bar 9 --provider offline
```
